# OSE agent operating contract
Read spec/OSE-SPEC.md, docs/status.md, tasks/README.md, relevant ADRs/interfaces and your task card. If missing, create only as assigned. Git and checked-in documents are the shared memory; never assume access to another model's conversation. Work within assigned scope; use a separate branch/worktree. Verify target MVS 3.8j APIs from pinned sources, not modern z/OS assumptions. Never claim a test ran unless it did; capture command, RC and evidence. No shared guest mutation without lease, no production access, no secrets, no unapproved paid API or dependency changes. Escalate privileged code, security boundaries, ambiguous ABI and repeated failures. Update task handoff, docs and tests before requesting review. Independent review required for security and privileged changes. Human owns merges and releases. See specification sections 7–8 for routing, cost and documentation rules.
